# Paquetes · Escritorio

Instalados por `packages.sh`. Hyprland es la ventana y el escritorio; la barra, los anillos, el lanzador y los paneles los dibuja Quickshell (ver [escritorio](../escritorio.md)).

| Paquete | Origen | Para qué sirve |
|---|---|---|
| `hyprland` | pacman | Gestor de ventanas (Wayland) |
| `xdg-desktop-portal-hyprland` | pacman | Portales: capturas de pantalla y compartir pantalla |
| `xdg-desktop-portal-gtk` | pacman | Avisa a Chrome y a las apps de que el sistema es oscuro (sin él salen claras) |
| `polkit` | pacman | Ventanas de permisos de administrador |
| `awww` | pacman | Fondos de pantalla con transición (antes `swww`) |
| `dunst` | pacman | Notificaciones |
| `rofi` | pacman | Lanzador de respaldo (`Super + Shift + Espacio`) |
| `grim` · `slurp` | pacman | Capturas de pantalla y selección de región |
| `wl-clipboard` | pacman | Portapapeles desde la terminal |
| `brightnessctl` | pacman | Brillo de la pantalla |
| `playerctl` | pacman | Teclas multimedia (play, siguiente, anterior) |
| `xdg-user-dirs` | pacman | Carpetas del usuario (Imágenes, Descargas…) |
| `quickshell-git` | AUR | El motor del escritorio propio (barra, paneles, bloqueo) |
