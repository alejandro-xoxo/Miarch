# Atajos

`Super` es la tecla de Windows.

| Atajo | Acción |
|---|---|
| `Super + Enter` | Terminal (kitty) |
| `Super + Espacio` | Lanzador de apps |
| `Super + Shift + Espacio` | rofi (lanzador de respaldo) |
| `Super + Shift + Q` | Cerrar ventana |
| `Super + L` | Bloquear pantalla |
| `Super + Esc` | Ajustes del equipo |
| `Super + Shift + Esc` | Menú de energía, de más a menos útil: **B**loquear, **S**uspender, **A**pagar, **R**einiciar y **C**errar sesión. Cada opción explica lo que hace; se elige con `↑` `↓` y `Enter` o con su letra. Apagar, reiniciar y cerrar sesión piden una segunda pulsación |
| `Super + W` | Cambiar wallpaper (y los colores) |
| `Super + B` | Navegador (Chrome) |
| `Super + V` · `Super + C` | VS Code · Claude Desktop |
| `Super + E` | Archivos (Dolphin) |
| `Super + F` | Ventana flotante |
| `Super + P` · `Super + J` | Pseudo-mosaico · cambiar la división |
| `Super + flechas` | Mover el foco |
| `Super + 1…0` · `+ Shift` | Ir al escritorio · mover la ventana ahí |
| `Super + S` · `+ Shift` | Escritorio especial "magic" · mover la ventana |
| `Super + rueda` | Cambiar de escritorio |
| `Super + clic izq./der. arrastrando` | Mover · redimensionar ventana |
| `Super + .` | Captura de una región al portapapeles |
| `Super + Ctrl + Shift + M` | Salida de emergencia: cierra Hyprland al instante, sin confirmar. Funciona aunque el escritorio (Quickshell) se cuelgue |
| Teclas de volumen, brillo y multimedia | Funcionan también con la pantalla bloqueada |
