# Paquetes · Terminal y herramientas

| Paquete | Para qué sirve |
|---|---|
| `kitty` | Terminal (colores del wallpaper, ver [escritorio](../escritorio.md)) |
| `zsh` | Shell (con Oh My Zsh, ver [zsh](../zsh.md)) |
| `neovim` | Editor de terminal (Lazy.nvim instala sus plugins solo) |
| `eza` | `ls` moderno, con íconos |
| `fastfetch` | Resumen del sistema al abrir la terminal (`miarch-fetch` lo adapta a la ventana) |
| `btop` | Monitor de recursos |
| `python` · `python-pillow` | Scripts de Miarch: colores del wallpaper, Wi‑Fi, información |
| `qt6-imageformats` | Imágenes webp en Quickshell (portadas de música) |
