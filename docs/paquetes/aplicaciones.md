# Paquetes · Aplicaciones

| Paquete | Origen | Para qué sirve |
|---|---|---|
| `dolphin` | pacman | Gestor de archivos (`Super + E`), con el estilo del escritorio |
| `qt6ct` · `breeze-icons` | pacman | Tema de las apps de Qt (paleta, tipografía) e íconos oscuros |
| `steam` | multilib | Steam y todo lo necesario para jugar: ver [juegos](../paquetes/juegos.md) |
| `spotify-launcher` | pacman | Spotify (la tarjeta de música lo detecta solo) |
| `blender` | pacman | Modelado, animación y render 3D (Blender). El visor usa la GPU; el render con Cycles usa la CPU en gráficas Intel antiguas (UHD 620 y similares) |
| `google-chrome` | AUR | Navegador (`Super + B`); flags de Wayland en `config/chrome/` |
| `visual-studio-code-bin` | AUR | VS Code (`Super + V`) |
| `claude-desktop` | AUR | Claude Desktop (se abre desde el menú de IA, `Super + C`) |

> **Crunchyroll**: no hay paquete; es una ventana de Chrome con la web (usa Widevine de Chrome); aparece en el lanzador `Super + Espacio`.

Los paquetes de AUR son de la comunidad y **no están firmados por Arch**. Ver [instalación](../instalacion.md#seguridad).
